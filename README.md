# 🚀 CodeVerse Learning Hub

> **Learn • Practice • Grow**

CodeVerse Learning Hub is a student-friendly web application that provides carefully curated YouTube playlists for learning programming languages in **Telugu** and **English**. It is designed to help beginners and engineering students learn programming in a structured and organized way.

---

## 📌 Project Overview

Searching for the best programming tutorials on YouTube can be time-consuming. CodeVerse Learning Hub solves this problem by organizing high-quality playlists into one platform.

Users can:
- 📺 Watch curated YouTube playlists
- 📚 Learn in Telugu and English
- ⭐ Save favorite courses
- 📝 Take personal notes
- 📊 Track learning progress
- 🔍 Search programming languages
- 🌙 Switch between Light & Dark Mode
- 🧠 Take quizzes (Future)
- 🏆 Earn certificates (Future)

---

# 🎯 Objectives

- Make programming education freely accessible.
- Help beginners choose the best learning resources.
- Reduce time spent searching for tutorials.
- Provide a clean and responsive user interface.
- Encourage self-learning among students.
